# mono Music // High-Fidelity Phonograph Console (Telugu 2000–2026)

[![Live Demo](https://img.shields.io/badge/Chrome_PWA-Installable-black?style=for-the-badge&logo=googlechrome)](https://mono-music.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-black.svg?style=for-the-badge)](LICENSE)

An authentic, 1964 vintage paper-and-ink phonograph console and mobile turntable web application dedicated to high-fidelity Telugu cinema soundtracks (2000–2026).

---

## Features

- **Vintage Vinyl Platter**: Microgroove LP platter spinning at authentic 33⅓ and 45 RPM speeds.
- **Dynamic Center Label**: Displays track title, composer, singers, movie, and release year in vintage typography.
- **Stylus Tonearm**: Pivots automatically onto the vinyl grooves when playing and returns to the armrest when stopped.
- **Ballistic Analog VU Meters**: Dual-channel decibel needles calibrated to realistic ballistic dynamics and damping.
- **Acoustic Monogram Emblem**: Interactive letterpress emblem chime with Web Audio oscillator synthesis.
- **Analog Surface Crackle**: Vintage 1960s vinyl dust and surface crackle generator with toggle switch.
- **Spotify-Style Discovery**:
  - Filter chips: **ALL**, **MASS 🔥**, **MELODIES 🎵**, **ROMANTIC ❤️**, **FOLK SONGS 🪕**, **LIKED SONGS ♥**, and **UPLOADS**.
  - Live auto-suggest dropdown and full movie album exploration.
  - Title-based strict de-duplication across all Telugu compilation releases.
- **Offline Download**: Download any song directly to your device with one click (`⬇`).
- **Sleep Timer**: Built-in 15m, 30m, and 60m turntable motor sleep timer.
- **Progressive Web App (PWA)**: Installable directly in Google Chrome as a standalone, borderless desktop or mobile application.

## Local Development

```bash
# Clone the repository
git clone https://github.com/Hemanthkalagar/mono-music.git
cd mono-music

# Start the Python production server
python server.py
```

Then open your browser to:
- **Desktop Web Console**: [http://localhost:3000](http://localhost:3000)
- **Mobile Turntable**: [http://localhost:3000/mobile](http://localhost:3000/mobile)
